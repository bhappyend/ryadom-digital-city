# Рядом by Patchvale

Городской каталог Digital City: Next.js, NestJS, PostgreSQL/PostGIS, Redis и MapLibre. Пилот карты и маршрутов — Смоленск. Наличие организации в открытом каталоге не означает платную подписку или подтверждённое владение.

## Размещение на сервере

Пошаговая инструкция, Docker-образы, домен, HTTPS, миграции, перенос каталога, первый администратор и резервные копии: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). Production-настройки — `.env.production.example`. Секреты заполняются на сервере; сервер пока не опубликован.

## Локальная разработка

Node.js 22.12+ и npm10.9+, Docker с Compose. Первичная настройка DB/Redis и секретов — `docs/DEVOPS.md`, схема — `docs/DATABASE-ADMIN.md`.

```text
npm ci
docker compose --env-file infra/.env.local up -d --wait db redis
npm run build:shared
npm run dev:api
```

В другом терминале: `npm run dev:web`. Web — http://127.0.0.1:3000, API — http://127.0.0.1:3001. Локальный `infra/.env.local` содержит секреты: его нельзя публиковать.

## Проверка и пакет исходников

```text
npm run typecheck
npm test
npm run contracts:check
npm run contracts:accounts:check
npm run build
node scripts/package-release.mjs
```

Последняя команда создаёт `release/ryadom-source.tar.gz`, SHA256 и список файлов. Пароли, локальные env, backup БД, пользовательские загрузки, node_modules и тестовые артефакты исключены. БД и медиа переносятся отдельно по инструкции. Пакет включает воспроизводимый лицензированный импорт Смоленска; национальная витрина не является заявлением о полном покрытии России.

## Разделы продукта

- Каталог: города, категории, поиск, карточки, карта, геокодирование и три режима маршрута при подключённых GIS.
- Администратор: `/auth/admin`; бизнесы, владельцы, подписки, CMS, медиа, отзывы и аудит. MFA обязательна. Общего пароля нет.
- Публичной регистрации нет. Владельцы входят по `/business`; учётные данные создаёт и сбрасывает администратор в CRM. Бизнес и публикацию проверяет уполномоченный оператор.
- CMS: черновик отделён от публикации. Оригинал отзыва сохраняется, редакторскую правку проверяет другой модератор.
- Медиа: проверка растровых файлов, WebP и закрытый доступ до публикации.
- Ежемесячная подписка: договорённость через https://vk.ru/desktopcoder или https://t.me/desktopcoder. Сумма задаётся оператором; учитываются фактически полученные средства и оплаченный период. Автоматических списаний нет.
- `/admin/demo/owners` и `/admin/demo/businesses`: 35 явно вымышленных владельцев и реальные организации открытого каталога. Они не выдаются за платных клиентов. Иллюстрации категорий не являются фотографиями организаций.

## Зависимости

GIS размещается отдельно: `docs/GIS.md`, `docs/GIS-LOCAL.md`. При недоступности сервисов интерфейс сообщает об этом. Яндекс/2ГИС требуют коммерческих разрешений, их фотографии и отзывы не скопированы. Почтовый провайдер не подключён: проверка бизнеса не подтверждает почту. Правовые тексты и реквизиты платформы нужно заполнить перед публикацией. Регистрация посетителей отключена; доступ владельцам выдаётся оператором.

Автоматические платежи, возвраты, выгрузка/удаление аккаунта не входят в текущий операторский сценарий; неподдерживаемые API не имитируют успех. Интеграции — `docs/INTEGRATIONS.md`, последние результаты приёмки — `docs/RELEASE.md`. Исторические отчёты сохранены в `docs/HANDOFFS/`. Работа ведётся в одном чате с ограниченными субагентами.
