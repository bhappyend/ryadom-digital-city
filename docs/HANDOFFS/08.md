## Решения / интеграция03

Точные примеры в `docs/MOTION.md`. В home03 напрямую импортировать `DigitalCityMotion` и `MapDemoScene`; первый один раз вставить внутри `<main id="main">`, вторым заменить существующую figure **внутри** section `data-motion="map-demo"`. Существующий copy/CTA оставить. Сцена включает свой caption «Демонстрация интерфейса · не навигационная карта», не вкладывать figure в figure. CSS module импортируется сценой. Сцена/Artwork остаются server components, без client barrel, чтобы геометрия не попала в client JS.

Селекторы соответствуют существующей03: `.hero-copy`, `.hero .hero-floating`, `#categories .category-link`, `#reviews .review`, `#reviews .review-empty`; все ограничены корнем `#main`. Статистика/рейтинги/контент не меняются. **CountUp не подключён:** текущие метрики03 не имеют opt-in атрибутов. Все значения/источники/даты сохраняются, придуманных данных нет.

Scroll-scrub — только декоративная последовательность zoom→markers→selection→route. SVG coordinates не GIS-данные. Mobile/touch/small viewport — статичный финальный пример; reduced motion/Save-Data/≤4 cores/≤4GB — все эффекты выключены. Нет scroll hijack, WebGL, dependency SDK, запросов к GIS/API, вечного rAF, background float loop. Пассивный scroll listener только в пределах видимой hero/сцены. Geometry cache/read-before-write; при hidden document кадры отменены и scroll listener снят, track сохраняется. Все observers/listeners/animations/frames/timers освобождаются.
