## Принятые решения и риски

- Никогда не сохранять application HTML/API/private/auth/admin/location/photos/map tiles; не подставлять offline document в URL с query. Public allowlist фиксирован и требует пересмотра при добавлении routes.
- Static credentials omit + exact response URL, no opaque/redirect, no private/no-store/no-cache/Vary auth; public immutable и корректный MIME обязательны. Версия cache не совпадает с Next buildId намеренно: whitelist допускает только content hashes, новый выпуск должен bump VERSION.
- `beforeinstallprompt` не универсален; принятие системного предложения не означает appinstalled. Native instruction modal честно описывает доступные пункты iOS/macOS/других браузеров.
- `clients.claim` и update другой вкладки сами по себе не вызывают reload. Timeout12s снимает intent; поздний event не перезагрузит пользователя. Worker уже activated другой вкладкой обрабатывается по явному клику.
- Нет офлайн-поиска/маршрута/полного приложения, нет регистрации SW в next dev, нет persisted geolocation/auth data. Старый production SW на том же origin dev нужно удалить вручную или использовать другой port.
- Ошибки хранения не ломают сетевой JS/CSS; install без надёжно сохранённого offline.html отклоняется.
- Browser HTTP cache отдельно требует server/proxy no-store для приватных/API/geolocation ответов; обход SW не заменяет server policy.
