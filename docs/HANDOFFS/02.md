## Реализация и решения

React 19, TypeScript strict (дополнительно exactOptionalPropertyTypes/noUncheckedIndexedAccess), source-first exports без отдельного bundler. Публичный API: Button, Brand, Icon, CategoryTile, Badge, Field, EmptyState, ProviderNotice и типы props. Полиморфизм Button не вводился. Нативные props/ref React 19, Button default type button, loading→disabled/busy, label/hint/error associations, named/decorative SVG, optional toggle state категорий. 29 inline SVG генерируются из доверенного оригинала, без dangerouslySetInnerHTML и runtime XML. 14 типов категорий соответствуют API. Навигация остаётся Next Link на уровне frontend.

CSS/JSON токены скопированы побайтово, палитра не менялась. `.dc-*` namespaced, base opt-in через `.dc-theme`, primary mint CTA, контрастные поля и secondary кнопки, focus-visible, reduced motion и forced colors. Градиенты/сторонние фото/фиктивные отзывы/рейтинги/статистика не добавлялись. Hero и map-demo остаются декоративными. Нет страниц, fake map, сети, geolocation/storage и API-связности в UI.

Локальный Manrope из `@fontsource-variable/manrope@5.3.0`: tarball SHA-512 совпал с npm registry integrity; сохранены оригинальный OFL и полный набор шести WOFF2. `fonts.css` использует family alias Manrope и same-origin URLs, чтобы исходный живой логотип получил нужный шрифт. Включены кириллица и ₽; не требуется внешний запрос браузера или npm fontsource dependency. Источники/пропорции/motion/accessibility/anti-slop review в DESIGN-SYSTEM, ограничения/размеры/права в ASSET-AUDIT.
