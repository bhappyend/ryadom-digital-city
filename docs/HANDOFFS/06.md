## Реализовано / решения

`@ryadom/gis` CommonJS/NodeNext strict. Nominatim `.search(q, city:City, signal?)`, Valhalla `.route(RouteRequest,signal?)` используют shared DTO/runtime schemas `@ryadom/types`1.0.0; parallel DTO не созданы. Точные зависимости `@ryadom/types:0.1.0`, `@maplibre/maplibre-gl-style-spec:26.11.0` (registry checked). Root controlled installation выполнил другой владелец;06 только сообщил manifest/dependency потребности.

Native Node22 fetch: fixed endpoint, exact deployment-owned origin allowlist, HTTPS/explicit private HTTP, no credentials/query/fragment/backslash/redirect; custom User-Agent; timeout охватывает body; client AbortSignal; bounded bytes/UTF8/JSON/schema/count/range. User URL не принимается. Public Nominatim запрещён адаптером. DNS/egress security обязан обеспечить deploy owner: allowlisted private self-hosted URLs допустимы, пакет не является DNS firewall.

Geocoding ограничен проверенными bounds enabled city,10 results, ru/countrycodes/bounded viewbox; нормализованные q/cache-key и provenance (получение не выдаётся за OSM update). Пустой provider result остаётся пустым; ошибка не маскируется.

Маршруты `walking→pedestrian`, `cycling→bicycle`, `driving→auto`; two break locations / one leg; стандартный Valhalla JSON polyline6→валидный GeoJSON `[lon,lat]`, km→meters, maneuver indices/location/time/length. Request span<=100km из общих DTO, geometry<=20k, maneuvers<=2k. Public decoder поддерживает5/6. Никаких fake straight-line routes.

`ProviderUnavailable` безопасно диагностирует reason, `toProviderState` возвращает общий public provider-state. Valhalla HTTP400 bounded JSON/error442→`no_route`/`coverage_missing`, API должен404; другие dependency errors503. `InvalidGisInput`→400; cancelled клиента обработать без ответа в закрытое соединение.

`@ryadom/gis/map` — browser-safe subpath без server code/env/runtime imports. Pure `createDarkMapStyle(DarkMapOptions)` и `getMapPresentation` с explicit unavailable; OpenMapTiles source-layer и fields изучены по официальной схеме. Water/road/building соответствуют `#0D4355/#2B424D/#193440`; labels14px+, Cyrillic name preference, attribution OSM/OpenMapTiles. В JSON нет декоративной карты/POI/route/generated hero и demo endpoints. Нужны actual tiles/glyphs/styles endpoint, а не только корректный JSON.

`docs/GIS.md`: параметры API/frontend и фактические hardcoded API limits; exact links OSM Smolensk oblast42M + state/MD5; лицензии/setup/ресурсный план с distinction estimates vs measurements; запрет Russia/planet/unbounded public providers; контрольный адрес с реальным ответом.
