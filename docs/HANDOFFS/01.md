## Реализовано и принятые решения

- npm workspaces с minimal root devDependencies TS/Vitest/Node types и runtime Zod в types; strict TS configs web/api. Проверено разрешение config exports для extends без диагностик.
- Скомпилированный CommonJS @ryadom/types с declarations и единым import/require export. Place/City/Category/Provenance, nearby query/data, stats, platform reviews, geocode/routes/map, report request/receipt, success/error envelopes. Все DTO доступны через schemas и inferred types.
- 14 category IDs соответствуют оригинальным tile/marker Assets. Никаких организаций, адресных seed, отзывов или метрик не придумано.
- WGS84 lon/lat, GeoJSON LineString [lon,lat], метры/секунды, walking/driving/cycling. Radius300..10000, limit<=50, page<=100, query длины и route span<=100km, ограниченные geometry/maneuvers. Strict scalar parsing без Boolean('false')/Number('').
- Explicit unavailable provider states и 503; map config200 с discriminated data.status; отказ провайдера не маскируется пустой выдачей. Reports202 только после durable записи. Anonymous reports без contact/URL/file полей.
- Generated OpenAPI3.1 (JSON-синтаксис, валидный YAML1.2), 10 операций; io=input для query defaults (radius/page/limit/openNow необязательны), output для response. Дополнительные cross-field refinements описаны в info и ARCHITECTURE; вычисление Haversine/ссылки манёвров не выражаются обычным JSON Schema.
- ARCHITECTURE: ownership, версии/peer compatibility, API examples, DB/GIS boundary, security/performance constraints и критерии этапов1/2/3. INTEGRATIONS: provenance/licensing, собственные providers, российский hosting target и отсутствующие решения. Sites local-only, Next/Nest/PostGIS сохранены; Workers не заменяет архитектуру.
