## Решения

`PUBLIC_SITE_URL` — только статическая серверная deployment-конфигурация, не Host/request. Нет example/localhost production fallback. HTTPS public DNS origin без credentials/path/query/hash; local origin возможен лишь при трёх явных dev условиях. Индексация требует одновременно NODE_ENV=production, SITE_ENVIRONMENT=production и SEO_INDEXING_ENABLED=true. Иначе robots Disallow `/`, sitemap пуст, helper metadata noindex; JSON-LD выключен. Robots не умеет noindex, поэтому до интеграции03 noindex на самих страницах не утверждается. Auth/staging access control обязательны отдельно.

Сейчас sitemap только `/` и `/map` — существующие публичные static pages, без invented lastModified. Полного Place export в контракте1.0.0 нет; nearby search никогда не используется как полный каталог. Городских SEO routes нет: не синтезировались. Canonical не сохраняет query/геолокацию, query-варианты03 должен помечать hasSearchParams/noindex.

JSON-LD повторно валидирует Place DTO. Нет aggregateRating/reviews, free-form hours interpretation, fake price/photos/claims; неизвестные/null optional facts опущены. Категории из CATEGORIES: широкий Place для неоднозначных категорий, общий LocalBusiness для business taxonomy; нет произвольных узких schema types. Original hero только декоративный OG, не фото организации/карта. Контакты и источник проверены, scripts сериализуются с `< > & U+2028 U+2029` escapes. SearchAction не создан из несуществующего универсального текстового endpoint.

Аналитика выключена: SDK/pixel/beacon/replay/events/storage не добавлялись. События в документации — будущая минимальная спецификация, не живые метрики. Провайдер/consent/retention/регион/доступ/удаление и legal review не определены. CWV целей недостаточно для приёмки: реальных lab/field измерений16 нет.
