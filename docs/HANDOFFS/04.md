## Реализовано

Nest12.6.3/Express5.3.0, API3001 /api/v1. Cities,14taxonomy categories, places/near, places/:slug, stats, platform-reviews, geocode, routes, map/config, reports. /health и /health/live — process liveness; /health/ready проверяет DB+Redis, показывает configured/disabled GIS без утверждения реальной работоспособности провайдера.

Контракты импортируются @ryadom/types; strict input и response-schema boundaries, server UUID metadata, generic safe errors, no-store. Без DB/provider явный503, карта200 с discriminated unavailable, подтверждённый no_route404. Нет fake memory catalog, login/auth/business/payments API.

DB runtime адаптер использует @ryadom/db/compiled и CatalogRepository05: параметризованные запросы/фильтры остаются в DB package. APP_DATABASE_URL runtime role; API не требует migration DATABASE_URL. Report202 только после durable INSERT, unknown/inactive place404. Redis обязателен для reports; при отказе закрыто503. Shared atomic fixed-window Redis rate limits60read/min,10geocode/min,10routes/min,5reports/hour, Retry-After до конца окна. Read/geo fallback bounded per-process; одновременно максимум4geocode/2route без очереди. Redis IP keys HMAC+TTL, raw IP не сохраняется.

Origin exact allowlist, strict JSON16KiB, no compressed body, URL4KiB, Helmet/CSP/no-referrer, safe error mapping, no raw q/body/location logging, trusted proxy defaultfalse. Client abort передаётся GIS. DB statement budget3s по05, API ожидание3.5s; GIS5s, API ожидание5.5s, output5MiB. GIS fixed operator URLs/allowlists, redirects/body/schema controls в06. MAP_STYLE_URL проверяется отдельным exact allowlist.

F-13-01 исправлен: Origin/Fetch Metadata/report rate policy привязаны к выбранному Nest handler через guard, а не строковому req.path. Trailing slash/uppercase не обходят защиту; encoded/double-slash варианты проверены. Независимый targeted retest13 также FIXED/RB-00 CLOSED — см. HANDOFF13 hashes и матрицу. Это не закрытие общего security release gate.

Canonical env: CORS_ORIGINS, APP_DATABASE_URL, REDIS_URL, GEOCODER_PROVIDER, NOMINATIM_URL, VALHALLA_URL, GIS_ALLOWED_ORIGINS, GIS_ALLOW_HTTP, GIS_USER_AGENT, MAP_STYLE_URL/MAP_ALLOWED_ORIGINS. GIS timeout/response budgets в API жёстко5s/4MiB; advertised GIS_TIMEOUT_MS/GIS_MAX_RESPONSE_BYTES пока не меняют их. Root wrapper17 передаёт только runtime DB/Redis из ignored infra/.env.local. Production обычный node dist/main.js, без TS loader; compiled shared packages обязательны.
