# Аудит дизайн-поставки — задача 02

Дата: 2026-11-27. Проверены все файлы `ryadom-digital-city/assets`, README, MASTER PROMPT, CSS/JSON токены и пример webmanifest. Исходный каталог не изменён. Копии находятся в `apps/web/public/assets`; baseline с SHA-256, размером и dimensions/viewBox для каждого файла — `packages/ui/asset-manifest.json`.

## Состав и целостность

Всего **72 оригинальных файла, 2 609 008 байт**: 63 SVG, 6 PNG, 2 WebP, 1 ICO. Все 72 копии совпадают побайтово с исходниками. CSS и JSON токены также совпадают побайтово с оригиналами. Ни одного оригинального фото организации или отдельного аватара в поставке нет.

| Группа | Количество | Назначение |
|---|---:|---|
| backgrounds | 2 | Сгенерированный художественный hero, две ширины; не карта и не документальная фотография Смоленска. |
| brand | 9 | Три SVG: horizontal/mark/favicon; пять PNG для PWA/Apple и один ICO. Логотип содержит живую кириллицу, не outlines. |
| icons | 43 | 29 контурных currentColor SVG и 14 готовых цветных tiles. |
| markers | 15 | 14 категорий + user-position. Применение на реальной карте — только в привязке к проверенным координатам. |
| illustrations | 2 | map-demo и neon-wave — декоративные SVG. Условная карта не может служить реальной навигацией. |
| reference | 1 | Коллаж digital-city-mockup.png; только дизайн-референс. |

Все 63 SVG распарсены стандартным XML parser: проверены корневой namespace, viewBox, допустимые tags; отсутствуют script/foreignObject, DOCTYPE/ENTITY, on*-обработчики, href/src, встроенные style и внешние URL. Все `url(#id)` ссылаются на существующий локальный ID. Это проверка конкретной поставки, не разрешение загружать произвольный пользовательский SVG.

29 outline SVG конвертированы в статический JSX с сохранением геометрии и currentColor; генератор повторно сравнивает результат с источником. Применение таких SVG через img не наследует цвет страницы, поэтому `Icon` использует inline SVG. Цветные tiles и markers намеренно сохраняют заданные цвета, для них img допустим. SVG-ссылки не подставляются из произвольных пользовательских URL.

## Manifest и PWA

`design/manifest.example.webmanifest` корректный JSON: русский язык, имя «Рядом by Patchvale», theme/background `#061217`, scope/start/id `/`, standalone. Все четыре URL `/assets/brand/{icon,maskable}-{192,512}.png` разрешаются в копии, размеры и purpose any/maskable проверены. Пример не был превращён в активный manifest: маршрут, scope и service worker принадлежат frontend/PWA. Не заявляется проверка установки, safe-area обрезки масок на устройствах, offline и cache-политики.

## Локальный шрифт — дополнительная разрешённая поставка

Шрифтов в оригинале нет. Для кириллицы добавлен **Manrope variable 200–800** из официального npm-пакета `@fontsource-variable/manrope@5.3.0`, лицензия OFL-1.1. Проверена SHA-512 integrity всего tarball из npm metadata, затем SHA-256 каждого сохранённого файла. Тарбол распакован выборочно в памяти; npm install и изменения root lock/package не выполнялись.

В `apps/web/public/assets/fonts/manrope/` находятся неизменённые LICENSE, wght.css и все шесть WOFF2 subsets пакета, а также `provenance.json` с URL, версией, датой, upstream integrity и локальными хэшами. CSS для реального подключения — `packages/ui/src/fonts.css`: family alias Manrope, абсолютные локальные URL. Проверены WOFF2 magic/declared length, наличие файлов по URL, объявленная кириллица U+0400–045F и диапазон с рублём U+20BD. Глифы не растеризованы отдельным font-tool и ещё не проверены в браузере; это задача интеграционной QA. Не выдавать проверку CSS unicode-range за проверку всех глифов.

Первоисточники: [npm tarball 5.3.0](https://registry.npmjs.org/@fontsource-variable/manrope/-/manrope-5.3.0.tgz), [официальное подключение Fontsource](https://fontsource.org/fonts/manrope/use), [лицензия и происхождение](https://fontsource.org/fonts/manrope/about). Исходный npm CSS использует Manrope Variable; alias в UI CSS нужен для сохранения исходного логотипа. При поставке обязательно сохранять LICENSE рядом со шрифтами.

## Ограничения контента и прав

- В архиве нет проверенной базы организаций, фотографий мест, аватаров, отзывов, статистики, API-ключей и реальной географической подложки. Не извлекать эти данные из screenshot.
- Нет отдельного бизнес-кабинета/device montage: frontend строит честную иллюстрацию интерфейса или использует доступные ресурсы с подписью демонстрации, без выдуманного роста бизнеса.
- Цветные assets были созданы заново под референс; README просит проверить права на название/логотип перед коммерческим запуском. Аудит не подтверждает юридическую чистоту товарного знака.
- Не выполнялись генерация новых картинок, сторонний поиск фото, скрейпинг организаций, подмена фото и публикация. Сторонняя добавка только открытый Manrope с поставленной лицензией.
- Reference PNG сохранён как запрошенная полная копия Assets, но приложение не должно импортировать его в пользовательский экран или preload. Это самый тяжёлый файл комплекта.

## Воспроизведение

Из корня репозитория: `python packages/ui/scripts/audit-assets.py`, `python packages/ui/scripts/generate-icons.py --check`. Python требует Pillow; в текущей среде он уже доступен, установка не выполнялась. Audit сравнивает assets с baseline, исходником и копией, проверяет токены/manifest/шрифт. `--write-manifest` применялся только один раз при создании baseline; для обычной проверки его не использовать. Хэши не заменяют лицензионную экспертизу и runtime-приёмку приложения.
